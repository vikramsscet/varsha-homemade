# 🍬 Varsha Homemade

A premium, modern, and responsive website for **Varsha Homemade**, showcasing authentic homemade Indian sweets, festive gift hampers, and custom orders. The website is designed to provide customers with an elegant browsing experience while making it easy to explore products and place orders via WhatsApp.

---

## 🌟 Features

- 🎨 Premium and elegant UI inspired by luxury Indian sweet boutiques
- 📱 Fully responsive (Desktop, Tablet & Mobile)
- ⚡ Fast loading and SEO optimized
- 💬 Floating WhatsApp "Order Now" button
- ✨ Smooth animations and transitions
- 🖼️ Beautiful image gallery with lightbox
- ⭐ Customer testimonials
- ❓ Interactive FAQ section
- 📍 Embedded Google Maps
- 📞 Contact form
- 🎁 Festival specials and gift hampers
- 🍬 Product showcase
- ♿ Accessibility-friendly design
